# zebrawood — 2026-10-28

**Title:** Zebrawood

**Brief:** Zebrawood veneer for the whole car: bold espresso-brown grain stripes on a blond honey ground, like a sheet of exotic striped timber. The grain is grown in 3D through the body, so the stripes run long and wavy down the sides, sweep across the hood, and curve into arches on the nose and tailgate without a break.
