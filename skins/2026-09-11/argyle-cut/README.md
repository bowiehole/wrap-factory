# argyle-cut

Ivory body with a high-contrast argyle diamond lattice in crimson and navy that tiles continuously in vehicle space (u=nose→tail, v=roof→rocker) — intersecting 45° diamonds wrapping around every panel, regenerated impression, no logos.

Continuous UV paint via buildUVMap — two phase-shifted 45° saw/abs waves in vehicle-space `(u,v)` so bands CROSS into an argyle diamond lattice wrapping every panel. Template alpha filled + dilate4. Ivory floor raised for coverage ≥0.97.
