# halftone

**DATE:** 2026-09-21  
**SLUG:** `halftone`

Deep ink-black body overprinted with overlapping cyan, magenta, and yellow circular CMYK-style halftone screens at classic print angles (~15°/75°/0°), high-contrast wrap-around field.

Structure = print-process dots (CMYK screens). Palette: near-black ink base + electric cyan + hot magenta + process yellow. Same motif seed on every panel.
