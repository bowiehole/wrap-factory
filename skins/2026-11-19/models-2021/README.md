# cobalt-weave — 2026-11-19

**Title:** Cobalt Weave

**Vehicle:** Model S 2021

**Brief:** Cobalt Weave for the whole car — a dense all-over woven textile in a bold basket weave: three-strand blocks of cream and cobalt threads alternating like a checkerboard, each thread rounded and shaded, with a dotted saffron accent thread. Laid out in surface meters so the weave runs continuously over hood, doors, corners and tail. Original design; no logos or text.
