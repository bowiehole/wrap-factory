# hex-comb

Charcoal-ink body with a dense honeycomb hex lattice — mint and coral cell walls, occasional filled accent cells tiling continuously in vehicle space via plane world-bake; regenerated hive impression, no logos/seals.

Plane world-field bake via `bake-world-field-around.mjs` (`--mapping=plane`) sampling `hexCombAt(u,v)` so mint/coral hex walls wrap continuously across every panel and door seam. Charcoal-ink floor. Coverage ≥0.97. Zero glass/wheel leak.
