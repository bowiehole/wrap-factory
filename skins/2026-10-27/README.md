# 2026-10-27 — Tie-Dye

**tie-dye** — Tie-Dye

**Brief:** A rainbow tie-dye spiral that wraps the whole car: magenta, orange, yellow, green, turquoise and violet bands swirl out from the middle of each side, cut by white crinkle lines where the cloth was folded. The dye is laid out in 3D on the body itself, so the bands run unbroken across the hood, fenders, nose, corners and tailgate.

**Vehicles:** Cybertruck, Model 3, Model 3 2024 Base, Model 3 2024 Performance, Model Y, Model Y 2025 Base, Model Y 2025 Premium, Model Y 2025 Performance, Model Y L, Model S 2021, Model S 2025 Plaid, Model X 2021

**Palette:** magenta (#e3127d), orange (#ff5a14), yellow (#ffd60a), green (#18b04a), turquoise (#0aa6d6), violet (#5a26c2), cotton (#f4efe6)
