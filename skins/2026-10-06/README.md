# Skins — 2026-10-06

**action-drip** — Action Drip

**Brief:** Studio action painting — a raw gallery-white canvas body flung with long looping skeins of jet-black enamel, overlaid with thinner cobalt, cadmium-red, and chrome-yellow pours, peppered with spatter and splat crowns, and on the upright panels a few gravity drips running straight down toward the rockers; world-metre 3D paint so every skein crosses the hood-to-fascia crease, door seams, and tail in one piece; regenerated studio impression, no artist style marks, no logos.
