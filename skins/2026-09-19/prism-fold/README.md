# prism-fold — 2026-09-19

**Brief:** Charcoal origami facet field with ice faces, indigo shadows, and tangerine crease highlights; continuous wrap via plane world-bake.

**Preview:** `preview/` holds site hero stills (Cybertruck front/side/front-quarter/rear-quarter + og + swatch) and `preview/{vehicle}/` stills for all 12 official vehicles.

**Structure:** Irregular origami / hard triangular facet field with crisp crease edges — not hex, argyle, radar rings, barcode bars, scales, tartan, or topo. Regenerated origami/facet impression only — no logos/seals/marks. Same motif seed on every panel (no role offset). Mapping = plane world-bake.
