# slash-field

Bone-cream body scored by bold vermillion and charcoal diagonal slash bands (~35° in vehicle space) that wrap continuously around every panel — high-contrast graphic cut fields, regenerated impression, no logos.

Continuous UV paint via buildUVMap — diagonal bands as function of (u·cosθ + v·sinθ) with soft edges. Template alpha filled + dilate4. Cream floor raised for coverage ≥0.97.
