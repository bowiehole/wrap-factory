**Brief:** same bone-cream vermillion/charcoal slash field; world-bake wrap-around remaster

**Date folder:** `2026-09-09` (original drop date kept; v1 `slash-field.png` files untouched).
**Bake:** GLB world `(along=nose→tail, heightV=roof→rocker)` via `bake-world-field.mjs` / seed 0 on every panel.
