# topo-blaze — 2026-11-22

**Title:** Topo Blaze

**Vehicle:** Model Y 2025 Base

**Brief:** Topo Blaze for the whole car — a bold topographic map: ink-black contour lines, with a heavier index line every fifth step, swirling over a blaze-orange ground and closing around bone-white summits. Laid out in surface meters so the terrain runs continuously over hood, doors, corners and tail. Original design; no logos or text.
