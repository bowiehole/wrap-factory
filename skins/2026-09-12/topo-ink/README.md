# topo-ink

Warm paper-cream body with a high-contrast topographic contour-map field — nested closed ink contours from a continuous vehicle-space height field, charcoal major/minor contour lines plus occasional cadmium index contours wrapping every panel continuously; regenerated map impression, no logos/seals.

Continuous UV paint via `buildUVMap` — nested level-set topographic contours from a multi-octave fbm height field in vehicle-space `(u,v)` so charcoal major/minor ink lines (plus occasional cadmium index contours) wrap continuously across every panel and door seam. Warm paper-cream floor raised for coverage ≥0.97. `dilate4` + clear outside template alpha. Zero glass/wheel leak.
