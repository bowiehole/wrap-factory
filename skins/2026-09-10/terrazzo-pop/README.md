# terrazzo-pop

Warm parchment body densely speckled with multi-color terrazzo chips (coral, teal, mustard, indigo, charcoal) — irregular chips of varying size that feel continuous across door seams via shared (u,v) noise; high-contrast graphic stone, regenerated impression, no logos.

Continuous UV paint via buildUVMap — anisotropic multi-scale terrazzo chips as hash/fbm cell noise in (u,v) so chips flow across door seams. Template alpha filled + dilate4. Parchment floor raised for coverage ≥0.97.
