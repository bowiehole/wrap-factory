How to load in Paint Shop
  1. Open Tesla Paint Shop on your vehicle’s touchscreen.
  2. Choose Custom / import wrap (wording varies by software version).
  3. Download the PNG for your exact vehicle variant from the list above.
  4. Transfer the file to the car (USB or supported share) and select it as the UV wrap atlas.
  5. Confirm the wrap maps correctly; if panels look mirrored, re-check you used the matching vehicle file.

These are digital UV texture packs for Paint Shop — not physical vinyl.
